# 未来相邻产品想法

这里保存讨论中出现、但不属于当前 Agent Orchestration Harness 职责的独立产品方向。它们只用于防止灵感丢失，不代表已经立项，也不在当前 Dreaming 中深入讨论。

## Agent 项目管理工具

未来可能开发一个位于 Harness 之上的 Agent 项目管理工具，用来管理多个项目，以及每个项目中的多个 thread。

可能承担的职责包括：

- 同一项目跨 thread 的信息传递、沉淀、汇总和汇报；
- 跨项目的知识、经验沉淀或总结；
- 跨项目、跨 thread 的身份资料卡目录、治理和资产管理；
- 多项目、多 thread 的实时进度看板。

当前 Harness 只聚焦单个 thread 生命周期。Thread 结束时形成的知识库、文档、总结和其他产物可以交给用户，也可能在未来成为项目管理工具的输入。两者的产品关系和交互方式尚未讨论。
