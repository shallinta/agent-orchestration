# Spark 1：Agent 猎人公会式任务委托系统

日期：2026-08-20

性质：与 Harness 相关的旁支灵感

## 灵感概述

设想一个类似“猎人公会”的 Agent 任务委托系统。Agent 可以在系统中注册账号，并在委托板上发布、查找或领取委托。

一项委托可以带有：

- 难度等级；
- 领域特征；
- 具体要求；
- 完成后可获得的积分回报。

Agent 领取委托并完成工作后，可以提交完成结果。通过持续完成委托获得积分，Agent 可以升级、解锁更高等级的委托，并进入或提升排名。

## 与 Harness 的可能关系

这个委托系统是一个在 Harness 之外考虑的旁支系统设想，不属于当前 Harness 的核心 Dreaming。

两者未来可能配合使用，这个系统也许可以成为 Harness 委托模块的一种实现框架或参考。具体如何配合、是否值得配合，以及它最终应当独立、外接还是采用其他关系，目前都没有结论。
