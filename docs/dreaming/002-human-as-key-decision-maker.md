# Dreaming 2：人从持续协调者转变为关键判断者

日期：2026-08-12

状态：当前阶段共识，可继续修正

## 这次只讨论什么

这次只讨论人希望从哪些工作中抽身，以及人是否仍应参与 Agent 协作。不讨论哪些节点必须由人审批，也不讨论 Harness 如何识别、暂停或呈现这些节点。

## 来自初始想法的事实

- 用户希望把分派任务、撰写和改写提示词、消息转发以及进展汇报交给主 Agent 与 Harness。
- 用户希望从这些持续发生的协调工作中抽身。
- 用户仍希望在重要节点签字和决策，例如方案最终评审、上线准出。

## 共同确认的核心需求

项目的目标不是消灭人的参与，而是改变人的参与位置。

人不应再被迫持续承担整理上下文、转发消息、催促下一步和维护进度等协调性劳动；理想情况下，Agent 协作可以自行连续运转。人在真正需要价值判断、风险接受或最终负责时介入，并保留最终决定权。

可以把这种变化概括为：

> 人从持续在线的协调者，转变为关键节点的判断者和最终责任人。

因此，“减少人的参与次数”本身不是成功标准。更重要的是减少低价值、机械性的参与，同时让人的每次介入都集中在确实需要人类判断的事情上。

## 这项共识暂时不意味着什么

- 不意味着已经确定哪些节点必须由人参与。
- 不意味着 Harness 或 Agent 可以自行判断所有事情。
- 不意味着所有项目和 thread 都需要相同程度的人工监督。
- 不意味着人的决定永远不可撤回或不可被 Agent 质疑。
- 不意味着已经确定权限、审批、暂停或通知机制。

“什么事情必须由人判断”“谁来识别需要人的时刻”“用户能否调整自治程度”，都留给后续 Dreaming 分别讨论。
