# 外部项目调研

本目录记录与 Agent Orchestration Harness 有对照价值的外部项目、框架、协议或产品调研。它用于理解现有方案解决了什么、没有解决什么，以及哪些经验值得后续借鉴。

这些记录：

- 不属于 `Stargazing N` 编号序列，不占用 Stargazing 编号；
- 不是已确认的产品需求、技术选型或架构决策；
- 可以对 Stargazing、产品设计或实现实验提供输入，但需要在对应阶段重新核实；
- 优先使用当前官方资料，并记录调研日期、证据范围、当前结论和明确限制。
